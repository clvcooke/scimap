# Baseline NIH Funding Tiles

MVT (Mapbox Vector Tiles) containing baseline NIH funding data across four geographic levels. Generated by `scripts/baseline.py` and hosted on Cloudflare R2.

## Tile Layers

| Layer                   | Tile path                                              | Max zoom | Features | Unique ID property |
| ----------------------- | ------------------------------------------------------ | -------- | -------- | ------------------ |
| States                  | `tiles_states_baseline_baseline-v1/{z}/{x}/{y}.pbf`    | 7        | 51       | `state`            |
| Counties                | `tiles_counties_baseline_baseline-v1/{z}/{x}/{y}.pbf`  | 9        | 3,143    | `FIPS`             |
| Congressional Districts | `tiles_districts_baseline_baseline-v1/{z}/{x}/{y}.pbf` | 9        | 436      | `GEOID`            |
| Cities (CBSA)           | `tiles_cities_baseline_baseline-v1/{z}/{x}/{y}.pbf`    | 9        | 925      | `CBSA_FIPS`        |

Tiles are served from `https://data.scienceimpacts.org/` (Cloudflare R2). Full URL example:

```
https://data.scienceimpacts.org/tiles_states_baseline_baseline-v1/{z}/{x}/{y}.pbf
```

## Feature Properties

Every feature across all layers has **80 properties**: one geographic ID, `pop_2024`, and 26 NIH institutes x 3 metrics.

### Property naming convention

```
{INSTITUTE}_{METRIC}
```

## Usage with deck.gl MVTLayer

The project uses `react-map-gl/maplibre` + `@deck.gl/geo-layers` MVTLayer. Here's how to consume a baseline tile layer:

```tsx
import { MVTLayer } from '@deck.gl/geo-layers'

const DOMAIN = 'https://data.scienceimpacts.org'

// Tile URLs
const TILES = {
  states: `${DOMAIN}/tiles_states_baseline_baseline-v1/{z}/{x}/{y}.pbf`,
  counties: `${DOMAIN}/tiles_counties_baseline_baseline-v1/{z}/{x}/{y}.pbf`,
  districts: `${DOMAIN}/tiles_districts_baseline_baseline-v1/{z}/{x}/{y}.pbf`,
  cities: `${DOMAIN}/tiles_cities_baseline_baseline-v1/{z}/{x}/{y}.pbf`,
}

// Unique ID property per layer (for highlighting/picking)
const UNIQUE_IDS = {
  states: 'state',
  counties: 'FIPS',
  districts: 'GEOID',
  cities: 'CBSA_FIPS',
}
```

### Single institute layer

```tsx
const layer = new MVTLayer({
  id: 'baseline-states',
  data: [TILES.states],
  binary: true,
  uniqueIdProperty: 'state',
  maxZoom: 7,
  pickable: true,
  getLineColor: [255, 255, 255, 60],
  lineWidthMinPixels: 1,
  getFillColor: (feature) => {
    const value = feature.properties.NIH_tot_raw_funding ?? 0
    // Apply your color scale here
    return colorize(value)
  },
})
```

### Summing multiple institutes

To color by combined funding from specific institutes, sum the relevant properties:

```tsx
const institutes = ['NCI', 'NIAID', 'NHLBI']
const metric = 'raw_funding'

getFillColor: (feature) => {
  const total = institutes
    .map((ic) => feature.properties[`${ic}_${metric}`] ?? 0)
    .reduce((sum, v) => sum + v, 0)
  return colorize(total)
}
```

### Per-capita normalization

Every feature includes `pop_2024` for per-capita calculations:

```tsx
getFillColor: (feature) => {
  const funding = feature.properties.NIH_tot_raw_funding ?? 0
  const pop = feature.properties.pop_2024 ?? 1
  const perCapita = funding / pop
  return colorize(perCapita)
}
```

## Regenerating Tiles

```bash
# Requires: pandas, geopandas, tippecanoe (via WSL on Windows), rclone
python scripts/baseline.py
```

### Input files

| File                | Location                                                    |
| ------------------- | ----------------------------------------------------------- |
| State CSV           | `data/baseline/baseline_state.csv`                          |
| County CSV          | `data/baseline/baseline_county.csv`                         |
| District CSV        | `data/baseline/baseline_district.csv`                       |
| City CSV            | `data/baseline/baseline_city.csv`                           |
| State boundaries    | `data/geo_ref/merged_data_states_CLIP.geojson`              |
| County boundaries   | `data/geo_ref/merged_data_counties_CLIP_Compress.geojson`   |
| District boundaries | `data/geo_ref/CongDist_shp_119/Congressional_Districts.shp` |
| CBSA boundaries     | `data/geo_ref/tl_2024_us_cbsa.shp`                          |

### Output files

Intermediate GeoJSON and tile directories are written to `scripts/outputs/`.

### Pipeline

1. Load geographic boundaries (GeoJSON or shapefile via geopandas)
2. Pivot CSV data: each geographic unit gets `{institute}_{metric}` columns
3. Merge pivoted data with geometries into a GeoJSON FeatureCollection
4. Generate MVT tiles with `tippecanoe` (runs through WSL on Windows)
5. Upload tiles to Cloudflare R2 with `rclone`
